# 纸织

在浏览器中将两张照片编织成纸艺作品。纯本地处理，无账号、图片上传或付费 API。

## 本地运行

在仓库目录运行 `python3 -m http.server 4173 --bind 127.0.0.1`，打开 http://127.0.0.1:4173 。请通过 HTTP 服务使用，不要直接双击 HTML。

## 使用

上传两张照片或选择示例，调整斜织、弧织、放射织法以及条宽、方向、纸感与保护区域，再导出 PNG。默认导出单张无字作品，可选择教学对照。

## 局限

内容建议依据边缘与纹理统计，不是语义识别。保护区是椭圆，不是自动分割；强对比第二主体仍可能影响主体辨识。放射为受约束扇形。图片最大 30 MB、5000 万像素；长边大于 3200 px 会缩小，透明区域填充暖纸色。
